🤖 Bot de Automação de Cadastro de Produtos

Este projeto consiste em um bot desenvolvido em Python para automatizar tarefas repetitivas de cadastro de produtos. A aplicação simula as ações de um usuário, abrindo o navegador, acessando o sistema de cadastro, realizando o login automaticamente e cadastrando os produtos a partir de uma base de dados. O objetivo é aumentar a produtividade, reduzir o tempo gasto em atividades manuais e minimizar erros durante o processo.

🎯 Objetivo do Projeto

Desenvolver uma solução capaz de automatizar o processo de cadastro de produtos em um sistema, eliminando tarefas repetitivas e tornando o fluxo de trabalho mais ágil e eficiente. Além disso, o projeto permitiu colocar em prática conceitos de automação, manipulação de dados e programação com Python.

🚀 Tecnologias Utilizadas

✨ Funcionalidades
Abre automaticamente o Google Chrome.
Digita e acessa a URL do sistema de cadastro.
Realiza o login automaticamente com usuário e senha.
Lê os dados de uma planilha utilizando a biblioteca Pandas.
Cadastra os produtos automaticamente, preenchendo os campos do sistema um a um.
Repete o processo até que todos os produtos da base de dados sejam cadastrados.
Reduz o tempo de execução e minimiza erros causados por tarefas manuais.
